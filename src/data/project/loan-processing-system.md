## Overview

A centralized microfinance system covering the client and loan lifecycle, repayment processing, cash control, ledger/reporting, and policy-driven configuration.

## The Problem

The manual and semi-manual loan process led to delays, inconsistencies in records, and difficulty tracking repayments and the overall cash position.

## My Approach

I designed structured workflows around client profiling, loan application, amortization, repayment, cash monitoring, and reporting so that the system could provide more consistent and auditable processing.

## Key Features

* Client profiling and loan application
* Amortization schedule and repayment processing
* Cash monitoring and ledger workflows
* T-accounts and financial reports
* User access and approval workflows

## Database Design

Core entities include Client Profile, Loan Profile, Repayment, Loan Product, and Amortization Profile. The design separates reusable product rules from transaction records to keep calculations and reporting manageable.

## Outcome

The system centralized the loan lifecycle and improved operational consistency, financial visibility, and day-to-day processing control.
